# AI Bone Studio V0.3 Beta

面向新手的本地角色准备 + 拆件检查 + FK 拼装动画网页。

## 直接试用

https://jobsff.github.io/ai-spine-pipeline/

顶部新增“角色与拆件 · V0.3”。无需 API：进入“拆件检查台”，点“试用练习拆件图”，展开规则网格，3 列 4 行切分，逐件确认后送入画板。练习素材是程序绘制的几何图，不是 AI 生成结果。

## 四个独立入口

1. 只有想法：写角色描述、追加需求；配置网关后明确点击生成，输入文字不会自动收费。
2. 已有原画：上传 PNG/JPEG/WebP，采用一个版本；设计稿可用像素矩形裁出视图，另存版本，原画保留。
3. 已有纯色部件图：直接上传检查台进行抠图。
4. 已有透明 PNG/WebP/部件 ZIP 或本工具工程：直接在原画板导入，不强制经过 AI 或重新抠图。

“准备工程”与“动画工程”分别保存：`.prep.json` 存原画版本、部件源图、候选和生成任务编号；`.project.json` 存贴图、拼装、骨骼、动作。两者均不保存网关口令 / 供应商密钥。原有 V0.2 动画工程打开时迁移为 V0.3，原文件不修改；V0.1 丢失图片的工程仍不能完整还原。

## 纯色抠图检查台

AI 部件只用高对比度不透明纯色背景，没有原生透明选项或回退路径。按角色选背景色，同批固定一色。先测背景，再抠图、去色、框选/网格/连通区域生成候选。连通区域不是语义零件，睫毛和高光可能需要归组。

支持原图、网格、白底、深色底预览；擦除 / 恢复原像素画笔；4 步画笔撤销；手动矩形框选；候选合并；语义名称指定；逐件确认 / 撤回 / 需修复 / 归档与恢复。重新抠图只改预览，不覆盖已确认图片。当前预览的画笔暂态不跨刷新保存；裁为候选后修正像素会保存，原图保留。

一个准备工程最多20角色版本、30源图、256候选、100MB内嵌PNG。首版单张抠图源图最多4,194,304像素（2048×2048）；超过会拒绝，不静默降画质。导出图集仍要求单件含边距不超过2048，请先处理尺寸。

抠图解决输出格式，不保证任意图片百分之百保真：主体同色、复杂半透明、发光、外部投影仍需手工处理。手机精细蒙版建议缩小素材或换电脑。背景一致率指采样边框，不是全图质量认证。

确认件可导出 ZIP（独立 RGBA PNG + manifest），或送入画板。会按工作区排开放置，不把素材板 source_bbox 当作人物初始坐标，不假装自动拼装。缺件仍提醒，允许确认后部分导入。

## 表情换图

在拼装/动作模式右侧“表情换图”中选择眼睛或嘴巴。上传闭眼 / 嘴型图片，或将已导入的另一个零件收为替换图；旧图片资源保留，可撤销。替换图独立调整位置和缩放，图片尺寸不同不影响同一部件的绑定关系。

先在拼装模式对齐替换图，再进入“做动作”。选择此刻显示的图片会记一帧；可隐藏部件、删除此刻换图帧，也可点“生成眨眼”。模板替换所选部件当前动作的换图轨道，不影响其他部件。左右眼各配置一次。

真正使用离散 attachment 轨道，不靠缩放假装闭眼；网页播放、工程保存、透明 PNG/序列帧和 Spine 3.8 导出都使用同一状态。

## 服务与任务

GitHub Pages 是静态站点，不能安全保存供应商密钥。公开站点默认没有收费生图服务；“生成”不会返回假结果。`apps/gateway` 提供 Node 和 Cloudflare Worker + DO + 私有 R2 服务代码。配置后填写网关 URL 和只存内存的服务访问口令；API Key / 模型由管理员在服务端设置。

支持 OpenAI Images、Gemini 原生 generateContent、明确开启对应能力的 Images 兼容服务。连接仅检查网关配置；实际生成会告知图片发往服务及费用未知，并要求确认。网络结果未知不自动重试。刷新只查状态，重开网页重新输入访问口令即可取回已有任务。

## 保留的 V0.2 功能

移动/旋转/缩放/镜像/层级/锁定/Pivot、40步撤销；父子骨骼、单骨刚性绑定、绘制关节链、FK；平移旋转等比缩放关键帧、呼吸/摆动模板；保存工程、Spine JSON+ATLAS+PNG、15fps透明序列帧。

没有 IK、网格多骨权重、变形、动态 draw-order、专业曲线、AI自动拼装或全部七动作。全身清单是素材规划，不是七套成品动作。Spine输出仍为3.8.99区域/FK/换图子集，不是 `.spine` 或 `.skel`，Laya/Cocos实际项目验收未完成。

## 本地开发与测试

```bash
cd apps/editor
npm install --ignore-scripts
npm test
npm run dev
# 或 npm run build 后打开 dist/AI-Bone-Studio.html
```

`tests/core.test.mjs` + `tests/v03.test.mjs` 为核心测试；`tests/browser_smoke.py` 保留旧版7组UI回归；`tests/v03_browser.py` 是新增完整流程。Python需要Playwright/Pillow/Chromium。

```bash
QA_OUT=./qa-v03 python tests/v03_browser.py
# CI有HTTP环境时额外测试 IndexedDB 和模拟网关恢复：
LIVE_URL=http://127.0.0.1:8765/ QA_OUT=./qa-v03-http python tests/v03_browser.py
```

源码保持 Canvas + TypeScript 无前端运行依赖，单文件构建不依赖外部 CDN。浏览器里看不到准备入口时，先刷新并确认页头版本0.3；构建与发布是两步，具体发布状态见仓库Actions。
