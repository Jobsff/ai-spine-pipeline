# V0.2 格式、引擎兼容与验收

## 当前承诺级别

输出按 Spine 3.8.99 JSON 的区域贴图/FK 子集编写，单元测试覆盖结构和独立坐标复算，浏览器已生成真实图集。**本次未运行 Laya SDK、Cocos SDK、Spine 官方 Runtime 或 Spine 编辑器，不是已获引擎认证的完整兼容实现。** 资源包内 `compatibility.json` 如实标记 `engineIntegrationTest: not-run-in-user-project`。

不能仅修改 skeleton.spine 获得新版本兼容。引擎必须使用与资源匹配的 3.8 运行库。旧 V0.1 的导出草稿不是有效游戏交付物，本版不继续使用它。

## 导出内容

- `character.json`：父骨在子骨之前；Spine 3.8 skins 数组；实际图片尺寸；region attachments；固定 slot 顺序；translate/rotate/scale 动画。
- `character.atlas`：3.8 旧版字段；不旋转、不裁边；文件名、region path 与 PNG 一致。
- `character_0.png` 等：真正 RGBA，straight alpha，2px 边缘扩展，4px 页边余量，单页最大 2048，最多 8 页。
- `images/`：单件 PNG，匹配 skeleton.images。
- `.project.json`：本工具带图片的可编辑工程；不是 Spine 的 `.spine` 工程。
- `IMPORT.md`、`examples/`、`asset-map.json`、`compatibility.json`：接入和审查资料。

编辑器坐标 X 向右、Y 向下、顺时针角度；导出 Y 和角度取反，根骨相对画板原点。图片 pivot 转成 region 中心偏移，避免镜像/缩放/旋转后跳位。源图集 source_bbox 不等于拼装坐标。

## 功能子集

已做：父子骨骼、单骨绑定、根变换、区域图片、每图镜像/缩放、初始透明度、固定前后层级、骨骼平移/旋转/正数等比缩放、线性及 step 数据采样、多个动作。UI 默认线性，不提供曲线编辑。

未做：IK、网格、多骨权重、FFD、约束、骨骼 shear/非等比缩放、动态 attachment 切换、动态 draw order、事件/混音、Spine 项目/二进制导出、4.x 输出器。

## LayaAir 3.x

以 LayaAir 3.3 文档的 Spine2DRenderNode 为基线；项目模块选择 Spine 3.8。共同复制 JSON/ATLAS/PNG 到 assets 下同一目录。动态加载 JSON 必须指定 `Laya.Loader.SPINE`。不要把 Spine .atlas 用 Laya 原生 atlas 加载器单独加载。

纹理按官方说明设置为 Default、启用 sRGB、不启用 Premultiply Alpha。本工具输出 straight alpha。参考 `examples/engine-smoke/LayaPlayer.ts` 或导出包内示例。不同 Laya 小版本需在实际 SDK 中检查接口声明；本次没有编译该示例。

## Cocos Creator 3.8.x

同目录导入 JSON、ATLAS、PNG；用 sp.Skeleton 的 SkeletonData 加载，关闭 premultipliedAlpha，选择导出动作名。代码示例在 examples。官方文档提醒某些 Spine 3.8 小版本有原生平台兼容问题（例如 3.8.75），因此网页能播也不替代原生平台验收。

## 每个项目必须完成的验收

1. 记录引擎精确版本、Spine Runtime 版本、目标平台。
2. 导入初始姿势：无版本错误、缺图；与编辑器对照位置、左右、镜像、尺寸和层级。
3. 用父子骨链测试旋转、平移、缩放；动作循环切换不跳变。
4. 白/黑背景检查 Alpha 边缘；实际移动设备检查显存和帧率；反复创建销毁检查泄漏。
5. 验证隐藏零件默认不显示、重复贴图共享、空动作时长、离画板边缘位置。

## 备用输出

透明单 PNG；15fps PNG 序列帧 + frames.json。序列帧无骨骼编辑性，但可按各引擎自己的帧动画流程接入，不需要 Spine Runtime。尚未自动生成 Laya/Cocos 专有 clip。
