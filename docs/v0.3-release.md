# V0.3 Beta 交付与测试记录

日期：2026-09-12。范围为已批准方案的第一阶段：角色准备 / 纯色部件检查 / 表情换图 / 安全网关实现。不是七动作与专业Spine全部功能。

## 已实现

可跳过的角色描述与上传、保留原图的版本采用/裁选；用途清单、局部与分组提示词；统一纯色色键、背景采样检查、边缘去色、框选/网格/连通候选、蒙版擦除恢复、归组、语义确认/归档、真实RGBA PNG ZIP、导入现有画板。已确认部件不被重新抠图覆盖。

新动画工程格式0.3，兼容0.2迁移。部件替换图带独立对齐参数，Clip持有离散attachment轨道；眨眼模板、隐藏、删帧、保存重开、Spine导出与序列帧均使用同一轨道。

后端有实际OpenAI Images与Gemini generateContent请求构建、响应解析和错误分类，不是UI占位。安全网关使用私有服务端密钥、内部团队口令、精确CORS、任务持久化、相同ID去重、限额、结果未知不自动重试和到期删除；R2存大图片，DO只存小元数据。Node存储为单进程私有目录，不支持共享目录多实例。

- Node 22.16.0 / TypeScript 5.8.3：编辑器 `npm test` **59项通过，0失败**，含原有33项回归。
- 网关 `npm test` **23项通过，0失败**。供应商、R2对象为受控模拟，不调用真实API。
- 原有浏览器回归：**7组通过**，含导入、保存、骨链、导出和390像素触摸拖动。
- 新增浏览器流程：**8组通过**，含角色版本/裁选、缺网关提示、12候选逐件确认与透明ZIP、确认像素不随重抠覆盖、画板衔接、闭眼替换/对齐/换图轨道/Spine/实际帧像素差异、准备工程往返、框选与蒙版撤销、390×844移动视口。
- 真实会话中的1536×1024女魔法师绿幕图已在检查台上传并处理，输出RGBA且Alpha范围0～255；边框采样一致度100%。这不是整图无损质量认证，细发丝/轮廓仍需白底深底检查。

关键修复：从距离抠图改进到同色相背景残留处理与局部前景拟合，增加暗绿色/黑色抗锯齿回归；避免失败加载继续复用旧源图的蒙版；绑定与移动pivot不破坏替换图；导入时剔除未知配置字段，密钥不会随手工修改的工程透传；R2图片写成功而索引陈旧时不得重复调用付费上游；无效限额配置拒绝启动。

本地浏览器通过 standalone set_content 执行，不把它称为HTTP或IndexedDB跨刷新测试。`tests/v03_browser.py` 设置LIVE_URL后额外执行真实源IndexedDB恢复和**模拟**网关提交/查询/重载恢复，CI执行结果以Actions日志为准；任务查询次数不增加付费提交次数。

## 上线与回退

Pages仍使用原地址，发布版本由根目录version.json的editorVersion/sourceCommit核对。main保留源码，site-build保留经测试的构建。gh-pages只推进到检查过的构建，不在源码里塞API Key。回退时选之前的site-build内容新建回退提交，再推到gh-pages，避免强推丢历史。

未配置网关时可用的是本地准备/拆件/编辑/导出；API入口清楚标记“需服务”。需要公开访问真实生图时，先部署受鉴权网关、配置服务端Secrets与实际模型，再分别验收文本生图和参考图编辑。
